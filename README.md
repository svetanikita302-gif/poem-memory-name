# Poem Memory Bot

Бесплатный Telegram-бот для заучивания стихотворений: Python 3.11+, aiogram 3.x, SQLite и открытый API русской Викитеки. Платные API не используются.

## Что умеет

- `/learn` — найти стих по названию и автору, показать варианты и полный текст для подтверждения или принять текст вручную.
- Оценить размер, строки, строфы, длину строк, лексику, синтаксис, повторы и общую сложность. Оценка лексики и инверсий эвристическая, без внешней NLP-модели.
- Разбить текст на смысловые блоки по 2–4 строки и провести нарастающее воспроизведение.
- `/train` — активное припоминание при 25%, 50%, 75% и 100% скрытых слов либо с опорой на первые буквы. Ответ проверяется по словам без учёта регистра, пунктуации и разницы «ё/е».
- Построить вечернее заучивание, утреннее повторение и дальнейшие интервалы. Длинный сложный текст делится на 2–3 вечерние части.
- Присылать напоминания с кнопкой тренировки, молчать ночью и менять следующий интервал по самооценке.
- `/plan` — показать план, `/progress` — статистику, `/cancel` — отменить стих и его напоминания.

Научные источники, параметры которых использованы в планировщике, перечислены в комментариях в `poem_bot/planning.py`.

## Запуск на своём компьютере

1. Установите Python 3.11 или новее.
2. Создайте окружение и установите зависимость:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

В Windows активация в PowerShell: `.venv\Scripts\Activate.ps1`.

3. Задайте токен только в окружении, не в коде:

```bash
export BOT_TOKEN="НОВЫЙ_ТОКЕН"
```

В Windows PowerShell: `$env:BOT_TOKEN="НОВЫЙ_ТОКЕН"`.

4. Проверьте локальную конфигурацию и запустите:

```bash
python main.py --check
python main.py
```

`--check` проверяет наличие токена и создание SQLite, но не делает запрос к Telegram. База по умолчанию — `poem_memory.db`. Путь можно изменить переменной `DATABASE_PATH`, часовой пояс — `TIMEZONE` (по умолчанию `Europe/Moscow`).

## Публикация на Render без программирования

### 1. Замените токен

Если токен уже был отправлен в чат или другому человеку, считайте его раскрытым:

1. Откройте в Telegram официальный `@BotFather`.
2. Отправьте `/revoke` и выберите своего бота.
3. BotFather выдаст новый токен. Старый перестанет работать.
4. Новый токен никому не отправляйте и не вставляйте в файлы проекта.

### 2. Поместите проект на GitHub

1. Зарегистрируйтесь или войдите на [github.com](https://github.com/).
2. Справа сверху нажмите **+ → New repository**.
3. В **Repository name** напишите `poem-memory-bot`, выберите **Public** или **Private**, нажмите **Create repository**.
4. На странице репозитория нажмите **uploading an existing file** либо **Add file → Upload files**.
5. Перетащите все файлы проекта, включая папку `poem_bot`. Файлы базы `.db` и секреты загружать не нужно.
6. Нажмите **Commit changes**.

### 3. Создайте сервис на Render

1. Войдите на [render.com](https://render.com/) через GitHub.
2. Нажмите **New + → Blueprint**.
3. Подключите GitHub, если Render попросит доступ, и выберите репозиторий `poem-memory-bot`.
4. Render прочитает `render.yaml`: бесплатный Web Service, Python 3.11, установку `requirements.txt`, команду `python main.py` и проверку `/health`.
5. Когда появится поле **BOT_TOKEN**, вставьте новый токен из BotFather. Нажмите **Apply / Deploy**.
6. Дождитесь окончания развёртывания. В **Logs** должны быть строки о запуске health-сервера и `Bot started`.
7. Откройте бота в Telegram и отправьте `/start`, затем `/learn`.

Если Blueprint недоступен, выберите **New + → Web Service**, подключите репозиторий и вручную укажите:

- **Build Command:** `pip install -r requirements.txt`
- **Start Command:** `python main.py`
- **Instance Type:** `Free`
- **Environment → Add Environment Variable:** `BOT_TOKEN` = новый токен
- Ещё одна переменная: `TIMEZONE` = `Europe/Moscow`
- **Health Check Path:** `/health`

### 4. Чтобы бесплатный Render не засыпал

Бесплатный Web Service может останавливаться после периода без входящих HTTP-запросов. Пока он спит, Telegram и напоминания могут задерживаться. Для постоянной работы добавьте бесплатный монитор:

1. В Render скопируйте адрес сервиса вида `https://poem-memory-bot.onrender.com`.
2. Зарегистрируйтесь на [uptimerobot.com](https://uptimerobot.com/) и создайте бесплатный монитор типа **HTTP(s)**.
3. В адрес вставьте `https://ВАШ-АДРЕС.onrender.com/health`.
4. Установите интервал 5 минут и сохраните.

Монитор бесплатно обращается к странице состояния и не даёт сервису заснуть. Он не получает токен и тексты стихов.

## Важное про хранение данных

Все расписания читаются из SQLite после обычного перезапуска процесса. Однако диск бесплатного Render временный: новый деплой или замена виртуальной машины могут удалить локальную базу. Это ограничение бесплатного хостинга, а не бота. Перед намеренным новым деплоем сохраните важные тексты отдельно. Постоянный Render Disk требует платного тарифа и здесь специально не используется.

## Источник стихов

Используется русская Викитека (`https://ru.wikisource.org/w/api.php`). Если страница недоступна, вариантов несколько или разметка не позволяет извлечь текст, бот предлагает ручной ввод. Авторские права на найденный текст и условия его использования остаются за соответствующими правообладателями; для классических текстов проверяйте выбранную редакцию.
